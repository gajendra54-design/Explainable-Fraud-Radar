# Data dictionary

All raw fields originate in `ml/data_generation/__init__.py`; all records and identifiers are synthetic. Currency is LKR for generated samples. Timestamps are timezone-aware UTC ISO 8601.

- `transaction_id`: unique string; seed plus sequence; idempotency key.
- `account_id`, `customer_id`: synthetic string references; one account per generated customer.
- `timestamp`: event time, UTC; drives chronological processing.
- `amount`: positive decimal, LKR; lognormal customer spending with overlapping anomalies.
- `currency`: three-character code restricted to LKR in generation, ML validation and the API. Other currencies are rejected because FX conversion is not implemented and amount features assume LKR.
- `merchant_id`: synthetic merchant reference; configured merchant count.
- `merchant_category`: Retail, Travel, Groceries, Electronics, Transfer or Dining.
- `channel`: Online, POS, Mobile or ATM.
- `country_code`, `customer_country`: transaction and home country; generator uses LK plus selected overseas countries.
- `device_id`: synthetic customer device; anomalous and some legitimate transactions use first-seen devices.
- `ip_risk_indicator`: synthetic continuous risk signal, 0–1, with overlapping distributions.
- `account_age_days`: integer elapsed days since a consistent synthetic account opening date. Each account receives a seeded initial age, then age increases with event time.
- `ground_truth_fraud_label`: binary simulation label, exclusively a training/evaluation outcome.
- `fraud_scenario_type`: simulation scenario for evaluation only; never a feature.

Engineered features are generated by `ml.features.engineer`:

- `log_amount`: ln(1 + amount), nonnegative.
- `amount_ratio`: current amount / prior account median, capped at 100; cold-start denominator 3,000.
- `count_1h`, `count_24h`: counts strictly before event time within the previous one/24 hours.
- `log_spend_24h`: ln(1 + previous 24-hour total), excludes current transaction.
- `minutes_since_previous`: elapsed minutes since prior account event, capped at 1,440; cold start 1,440.
- `new_device`, `new_merchant`: 0/1 first-seen indicators in account history. Accounts belonging to the same customer retain independent histories.
- `foreign_country`: 0/1 transaction country differs from home.
- `night_time`: 0/1 UTC event hour before 05:00; does not model local timezone.
- `ip_risk`: raw synthetic IP signal.
- `log_account_age`: ln(1 + account_age_days).

Raw records, engineered feature vectors, ground truth, predictions/explanations and investigator decisions are separate objects. Feature and model versions bind predictions to reproducible definitions. Unknown ground truth is not a negative label. The dataset validator quarantines missing required fields, duplicate identifiers, unsupported currencies, invalid/nonpositive amounts and impossible timestamps; large valid amounts remain eligible.
